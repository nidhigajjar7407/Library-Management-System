    <h1> Library Management System </h1>
  </hr>
    <ul>
      <li><h2>Project Description</h2></li>
    </hr>
      <p>Library Management System is a C++ project used to manage different types of library items such as Books, DVDs, and Magazines. The system allows the user to add items, display all items, search for an item by title, check out an item, and return an item. The project is mainly designed using Object-Oriented Programming (OOP) concepts.</p>
    </hr>
      <li><h2>What is incliuded in this project </h2></li>
      </hr>
        <ul>
          <li>Add Book</li>
          <li>Add DVD</li>
          <li>Add Magazine</li>
          <li>Display All Items</li>
          <li>Search Item</li>
          <li>Check Out Item</li>
          <li>Return Item</li>
          <li>Input Validation</li>
        </ul>
      </hr>
      <li><h2>How this project is made </h2></li>
    </hr>
      <p>The project starts with a LibraryItem base class that contains common information such as title, author, and due date. It also has virtual functions for checking out, returning, and displaying an item. Three classes — Book, DVD, and Magazines — are created by inheriting from LibraryItem. Each class has its own extra information. For example, a Book has an ISBN, a DVD has a duration, and a Magazine has an issue number. The program uses LibraryItem* pointers to store different types of items in the same array. Because the functions are virtual, the correct displayDetails(), checkOut(), or returnItem() function is called according to the actual type of item. Finally, the main() function provides a menu where the user can select different operations such as adding items, displaying items, searching, checking out, and returning items.</p>
